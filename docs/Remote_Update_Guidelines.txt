📦 Steps to send remote update to client (Steps):
Whenever you fix a bug or add a feature:

Increase version in package.json file (example "version": "1.0.1").
Git commit and push:

git add .
git commit -m "New features added v1.0.1"
git tag v1.0.1
git push origin main --tags

That's it! GitHub Actions will upload Windows build on GitHub Release, and client's app will be updated!
